
# Hello! 👋 I'm Gabriel Stroligo

### Senior Software Engineer · Front-end Specialist · Independent Product Builder

I'm a Senior Software Engineer and Front-end Specialist with **18+ years of experience** building scalable, accessible, and high-performance web applications and digital products.

Throughout my career, I've worked on complex projects for **government institutions, international organizations, NGOs, and the private sector**, including the **European Union Intellectual Property Office (EUIPO)** and the **Brazilian Judiciary (TJTO)**.

My expertise lies in modern front-end engineering, combining **software architecture, user experience, accessibility, and performance** to build reliable digital products.

My core technologies include:

**React · Vue · Nuxt · TypeScript · JavaScript · Tailwind CSS · Material UI · HTML · CSS**

I have extensive experience building **enterprise applications, government platforms, public services, design systems, responsive interfaces, API integrations, accessible applications (WCAG), and scalable component-based architectures**.

## 🚀 Independent Projects

Beyond my professional work, I dedicate my free time to exploring ideas and building independent digital products.

Currently, I'm developing **[JuntaTudo](https://juntatudo.app/)** — a personal finance and wealth management platform designed to bring financial accounts, credit cards, investments, assets, debts, and financial goals together in one place.

JuntaTudo is an opportunity to combine my experience in software engineering, product development, and user experience, taking a product from concept to implementation.

I enjoy the entire process: identifying problems, designing solutions, making architectural decisions, writing code, and continuously improving the product.
